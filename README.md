#### 5.什么是卷积神经网络 CNN
> 是什么
```java
卷积神经网络，简称 CNN，是深度学习领域里处理图像、视频等网格状数据的一把好手。
你可以把它想象成一个专门负责“找特征”的智能过滤器
它不像传统方法那样需要人工去规定怎么识别边缘或纹理，而是能自己从数据中学会这些规律。

```
> 原理
```java
输入图像 (Input Image)
      |
      v
+---------------------+
|   Convolution Layer |  <-- 特征提取：用多个滤波器滑动扫描，捕捉边缘、纹理等局部特征
|   (卷积层)           |
+----------+----------+
           |
           v
+---------------------+
|     Activation      |  <-- 激活函数：通常是 ReLU，引入非线性因素，让网络能学习复杂模式
|       (ReLU)        |
+----------+----------+
           |
           v
+---------------------+
|    Pooling Layer    |  <-- 降采样：缩小数据维度，保留主要特征，减少计算量并提高鲁棒性
|   (池化层)          |
+----------+----------+
           |
           v
      ... (重复上述 Conv-Act-Pool 模块多次，层数越深，提取的特征越抽象和高级) ...
           |
           v
+---------------------+
|   Flatten Layer     |  <-- 展平：将二维或多维的特征图拉成一维向量，准备进入分类器
|      (展平层)       |
+----------+----------+
           |
           v
+---------------------+
|   Fully Connected   |  <-- 全连接：整合所有局部特征，进行全局推理
|     Layers          |
|    (全连接层)       |
+----------+----------+
           |
           v
+---------------------+
|   Output Layer      |  <-- 输出层：通常接 Softmax 函数，输出各类别的概率分布
| (分类/回归结果)     |
+---------------------+
```
```java
1. 输入阶段：假设输入是一张 32x32 的彩色图片（RGB 三通道）。
2. 卷积阶段：多个滤波器（比如 5x5 大小）在图片上滑动，每个滤波器输出一个二维的特征图。如果有 6 个不同的滤波器，就会得到 6 张特征图，它们分别响应不同的视觉模式。
3. 激活与池化：经过 ReLU 激活后，负值被置零。接着通过池化（比如 2x2 的最大池化），将每张特征图的尺寸减半，从而降低数据维度。
4. 堆叠深化：上述过程会重复多次。随着网络层数加深，第一层可能检测到边缘，第二层组合成形状，更深层则能识别出物体部件甚至整体。
5. 分类输出：最后，所有高维特征被展平成一长串数字，输入到全连接层。全连接层就像是一个综合判断器，根据前面学到的所有线索，计算出这张图片属于各个类别的概率，概率最高的即为最终预测结果。
```

#### 6.什么是循环神经网络 RNN 
> 是什么
```java
循环神经网络 RNN 是一种专门处理“序列数据”的人工智能模型
你可以把它想象成一个有短期记忆的大脑。普通的神经网络在处理每个新数据时，是把它当成独立事件处理的，就像看一张张照片，前一张和后一张没关系。但 RNN 不同，它在处理当前数据的同时，还会保留一部分之前数据的“印象”，也就是内部状态。这种机制让它能够理解上下文和顺序

重点
   拥有短期记忆 让它能够理解上下文和顺序
```
***
> 原理
```java
RNN 的核心思想：
- 记忆性：通过隐藏状态 ht 携带历史信息，使网络具有“短期记忆”。
- 序列处理：按顺序处理输入数据，非常适合处理文本、语音、时间序列等具有时间依赖性的数据。

这是 RNN 最经典的“展开图”（Unrolled View），展示了时间步 t-1, t, t, t+1 之间的信息流动：

      输入 xt-1      输入 xt      输入 xt+1
         |             |            |
         v             v            v
    +----------+  +----------+  +----------+
    |          |  |          |  |          |
    | 隐藏层   |  | 隐藏层   |  | 隐藏层   |
    | (ht-1)   |  | (ht)     |  | (ht+1)   |
    |          |  |          |  |          |
    +----------+  +----------+  +----------+
         |             |            |
         v             v            v
      输出 yt-1      输出 yt      输出 yt+1
```

##### 7.人工智能的三要素
```java
 数据 + 算法 + 算力
简单比喻：
如果把人工智能比作做饭，
数据就是食材，
算法就是菜谱和烹饪技巧，
算力就是灶火和厨具的功率。
```
> 数据
```java
数据是人工智能的燃料。没有高质量、大规模的数据，模型就无法训练或无法达到良好的效果。
- 作用：用于训练模型，让机器从数据中学习规律。
- 特点：数据量越大、质量越高、标注越准确，模型的性能通常越好。
- 例子：图像识别需要数百万张带标签的图片；自然语言处理需要海量的文本语料。
```
> 算法
```java
算法是人工智能的大脑。它决定了如何从数据中提取信息、学习规律并进行预测或决策。
- 作用：定义模型的结构和学习方法。
- 常见类型：包括传统的机器学习算法（如线性回归、决策树）、深度学习算法（如卷积神经网络 CNN、循环神经网络 RNN、Transformer 等）。
- 特点：算法的先进性直接决定了模型的上限。
```
> 算力
```java
算力是人工智能的基础设施。它提供了处理海量数据和复杂算法所需的计算能力。
- 作用：加速模型的训练和推理过程。
- 硬件支撑：主要依赖 GPU（图形处理器）、TPU（张量处理器）以及高性能 CPU 和集群。
- 特点：随着模型规模变大（如大语言模型），对算力的需求呈指数级增长。
```

#### 8.机器学习的定义？通常有几种范式，分别是什么？
> 什么是机器学习
```java
让计算机通过数据自己找规律，而不是靠人写死规则
就像教小孩认苹果，你不是把苹果的所有特征写成代码，而是给他看很多苹果的照片，让他自己总结出苹果长什么样
```
> 三种范式
- 监督学习
```java
数据自带标签 有问题 也有答案
比如你告诉电脑每张照片里是猫还是狗，它学习后就能给新照片分类。典型的例子有垃圾邮件过滤、房价预测。
```
- 无监督学习
```java
数据没有标签，电脑得自己找结构
比如聚类分析，把用户分成不同的群体，或者降维，把复杂数据简化。典型的例子有客户细分、异常检测。
```
- 强化学习
```java
基于奖惩制度
这有点像训狗，通过奖励和惩罚来学习。电脑在环境中做动作，得到反馈，慢慢学会怎么得分最高。典型的例子有AlphaGo下围棋、机器人走路控制。
```

#### 9.怎么理解深度学习，他与传统的机器学习有什么区别？
> 是什么
```java
机器学习 - 让计算机自己通过数据找规律
深度学习是机器学习的一个子集，你可以把它理解为机器学习的“进阶版”或者“强力版”。
它最核心的工具是人工神经网络，特别是那种层数很深、结构复杂的网络，所以叫“深度”学习。  人工神经网络
```
> 与传统机器学习的区别
```java
传统机器学习流程：
原始数据 --> [人工特征工程] --> 特征向量 --> [传统算法(如SVM,决策树)] --> 预测结果

深度学习流程：
原始数据(图像/文本等) --> [深层神经网络] --> 自动提取特征 --> 预测结果


1. 核心差异：特征是怎么来的？

传统机器学习：
[人类专家] --(定义规则/挑选属性)-->[特征工程]--->[模型训练]
例子：识别苹果。
人工指定：颜色是红色、形状是圆形、直径大于5cm。
然后把这些数字喂给算法。

深度学习：
[原始图片]--->[神经网络层1]--->[神经网络层2]...--->[输出结果]
自动学习：第一层可能学会边缘，第二层学会形状，第三层学会整体轮廓。
不需要人工指定规则，模型自己从像素里“悟”出特征。

2. 算力需求对比

传统机器学习：
[普通CPU] --(轻松应对)--->[训练完成]
适合：小规模数据、结构化表格数据。

深度学习：
[大量GPU集群] --(火力全开)--->[训练完成]
适合：大规模非结构化数据(图片、语音、视频)。

核心总结
传统机器学习 = 人工智慧 + 算法
你需要懂业务，帮机器找规律。

深度学习 = 数据驱动 + 算法
你提供海量数据，让机器自己找规律。

```

#### 10.Transformer神经网络
Transformer是一种基于注意力机制的深度学习模型架构
> 原理
```java
一、核心结构图（纯文本示意）

输入文本 --> [编码层 Encoder] --> [解码层 Decoder] --> 输出文本

注意：现在的许多模型（如GPT）只使用编码层或只使用解码层，但标准Transformer包含这两部分。

1. 编码层 Encoder（理解输入）
[输入Embedding] --> [多头注意力机制] --> [前馈神经网络] --> [层归一化]
（这个过程重复多次，比如6层或12层）

2. 解码层 Decoder（生成输出）
[输出Embedding] --> [屏蔽多头注意力] --> [交叉注意力] --> [前馈神经网络] --> [层归一化]
（这个过程也重复多次）

总结一句话：
Transformer通过自注意力机制让模型同时关注输入序列的所有部分，并通过多头注意力和位置编码解决信息融合和顺序问题，从而实现了高效、强大的序列建模能力。
```

#### 11.什么是数据清洗
> 是什么
```java
数据清洗是数据处理过程中最基础也最关键的一环，简单说就是给数据“洗澡”，把里面脏兮兮、不靠谱的东西清理掉，让数据变得干净、整齐、可用。

脏数据
	1.重复的记录
	2.格式混乱的日期
    3.明显离谱的数值
    4.干脆是空的

场景
想象一下，你打算用一批数据训练一个 AI 模型，但这批数据里混入了很多错误信息，比如重复的记录、格式混乱的日期、明显离谱的数值，或者干脆是空的。如果不处理这些垃圾数据，模型学出来的东西就会歪掉，也就是我们常说的“垃圾进，垃圾出”。
```
> 数据清洗主要做哪些工作
```java
1. 处理缺失值：有些字段可能是空的。你可以选择直接删掉这条记录，也可以用平均值、中位数或众数来填补，甚至用算法预测缺失值。
2. 去除重复数据：同一份数据可能被录入了多次，重复数据会让模型对某些样本过度关注，导致偏差。
3. 纠正错误格式：比如日期写成“2026/1/1”和“Jan 1, 2026”混在一起，或者电话号码里多了空格和横杠。清洗时要统一格式，确保机器能正确理解。
4. 识别并处理异常值：比如一个人的年龄填了 200 岁，或者房价数据里出现了一个 1 元的极端低价。这些可能是录入错误，需要检查是保留、修正还是删除。
5. 统一编码和分类：比如性别字段里同时出现了“男”、“Male”、“M”、“1”，需要把它们统一成一种标准表示。
```

#### 12.什么是数据预处理
```java
数据预处理简单来说，就是把原始数据变成“能直接喂给算法吃”的干净数据的整个过程。
```
> 核心步骤
```java
第一是数据清洗。这是最基础的一步，主要处理缺失值、重复值和异常值。比如表格里有个年龄填的是负数，或者某行数据完全空白，这些都需要被修正或删除，否则它们会误导模型。

第二是数据转换。很多算法只能处理数值型数据，所以要把文字类别转换成数字。比如把“男”和“女”变成0和1，或者把日期格式统一成标准的时间戳。此外，还需要进行特征缩放，比如把身高（180左右）和收入（几万到几十万）缩放到同一个数量级，防止某个特征因为数值过大而主导整个模型。

第三是数据降维或特征选择。如果数据里的特征太多，不仅计算慢，还容易过拟合。这时候需要挑出最重要的几个特征，或者用技术手段把多个相关特征合并成一个，让数据变得更精简高效。
```

#### 13.什么是 ELT/ETL过程
> 是什么
```java
ETL 和 ELT 都是数据仓库和数据集成中常用的数据处理流程，它们的核心目的都是把分散在各个系统里的数据汇聚起来，变成可用的信息
```
> 什么是 ELT
```java
ELT 的全称是 Extract（抽取）、Load（加载）、Transform（转换）。它的核心原理可以简单概括为：先把原始数据全部搬进目标系统，再在目标系统内部进行加工。
// 1. Extract（抽取）
	// 1.1 第一步是抽取。从各种数据源比如数据库、API、日志文件里把数据抓出来。这一步通常很快，主要关注的是连接稳定性和数据完整性。
// 2.Load（加载）
	// 2.1 第二步是加载。这是 ELT 最关键的特点。把抓来的原始数据直接存入目标数据仓库或数据湖中，不做任何清洗或转换。这些数据通常以原始格式存在，可能包含重复、错误或者未标准化的字段。这样做的好处是速度极快，而且保留了数据的原始面貌，方便后续追溯
// 3.Transform（转换）
	// 3.1 利用目标数据仓库强大的计算引擎，对已加载的原始数据进行清洗、格式化、聚合、关联等操作。比如把日期格式统一，把空值填充，或者把多个表连接起来。因为现代云数据仓库比如 Snowflake、BigQuery 等都有极强的并行处理能力，所以这种在仓库内部进行的转换效率非常高。

ELT 的原理就是先搬运后加工。把数据仓库当成一个巨大的数据处理中心，原始数据先入库，再在库内通过 SQL 或其他工具进行清洗和分析。这种方式更灵活，扩展性更好，是目前大数据时代的主流数据处理模式。
```
***
> 什么是ETL
```java
// ETL 的全称是 Extract（抽取）、Transform（转换）、Load（加载）。它是数据仓库建设中最经典的数据处理流程。其核心原理可以概括为：在数据进入目标存储之前，先在源端或中间层完成所有的清洗、转换和整合工作，最后将处理好的干净数据写入目标系统。

// 1.抽取
	// 1.1 从各种异构的数据源中读取数据。这些源可能包括关系型数据库、Excel 文件、日志系统、第三方 API 等。抽取策略可以是全量抽取，也可以是增量抽取。全量就是把所有数据都搬过来，增量只搬最近变化的部分。这一步的关键是要尽量不影响源系统的性能，同时保证数据不丢失
// 2.转换
	// 2.1 这是 ETL 中最复杂、最耗时的环节。在数据从源系统出来、进入目标系统之间的这段时间，数据会在内存或临时存储中进行加工。常见的转换操作包括数据清洗比如去除重复值、处理空值、修正格式、统一编码。还有数据转换比如将货币单位换算、将日期格式标准化、将枚举值映射为中文描述。以及数据集成比如将多个表的数据通过关键字段进行关联、聚合计算、衍生新字段。这一步确保了进入数据仓库的数据是高质量、一致且符合业务逻辑的
// 3.加载
	// 3.1 将经过转换的干净数据写入目标数据仓库或数据集市。加载方式可以是覆盖加载，即清空原有数据重新写入，也可以是增量加载，只追加新增或更新的数据。加载完成后，数据就准备好供报表、分析和决策使用了。
```

#### 14.常用的数据清洗和预处理方法有哪些
- 处理缺失值
```java
- 删除法：如果缺失数据比例很小（如低于5%），可以直接删除含有缺失值的行或列。
- 填充法：
  - 数值型数据：用均值、中位数、众数填充，或者用上下相邻值（前向/后向填充）。
  - 分类数据：用众数填充，或新增一个“缺失”类别。
  - 高级填充：使用KNN、回归模型或多重插补（MICE）来预测缺失值。
- 标记法：将缺失值单独作为一个特征，保留其缺失信息。
```
- 处理异常值
```java
- 3σ原则：假设数据服从正态分布，超过均值3倍标准差的数据视为异常值。
- 箱线图法（IQR）：小于Q1-1.5IQR或大于Q3+1.5IQR的数据视为异常值，适用于非正态分布数据。
- 业务规则过滤：根据实际业务逻辑设定阈值，例如年龄不可能为负数，身高不可能超过3米。
- 处理策略：可以删除、修正（用边界值替换）、或保留（某些算法如树模型对异常值不敏感）。
```
- 数据转换
```java
- 归一化（Min-Max Scaling）：将数据缩放到[0,1]区间，适用于需要固定范围的场景。
- 标准化（Z-Score Standardization）：将数据转换为均值为0、标准差为1的分布，适用于大多数机器学习算法。
- 对数变换：用于处理右偏分布，使数据更接近正态分布。
- 离散化：将连续变量划分为区间（如分箱），常用于决策树或规则挖掘。
```
- 编码分类变量
```java
- 独热编码（One-Hot Encoding）：将类别型变量转换为多个二元变量，适用于无序且类别较少的情况。
- 标签编码（Label Encoding）：将类别映射为整数，适用于有序变量或树模型。
- 目标编码（Target Encoding）：用目标变量的均值替换类别值，适用于高基数类别变量，但需注意防止数据泄露。
- 哈希编码：用于高维稀疏数据，节省内存。
```
- 处理重复数据
```java
- 识别并删除完全重复的行。
- 根据业务逻辑判断是否保留最新记录或合并重复记录。
```
- 数据集成与合并
```java
- 多表关联：使用主键将不同来源的数据表连接起来。
- 解决命名冲突：统一字段名称、单位、格式（如日期格式统一为YYYY-MM-DD）。
- 解决数值冲突：当同一实体在不同表中值不一致时，根据可信度或时间戳选择权威来源。
```
- 文本数据预处理（针对NLP任务）
```java
- 清洗：去除HTML标签、特殊字符、多余空格。
- 分词：将文本切分为单词或子词。
- 去停用词：移除无实际意义的常见词（如“的”、“是”）。
- 词干提取/词形还原：将词汇还原为基本形式（如“running”还原为“run”）。
- 向量化：使用TF-IDF、Word2Vec、BERT等方法将文本转换为数值向量。
```

#### 15.常见的数据分析方法有哪些？
- 描述性分析（Descriptive Analysis）
```java
这是最基础的分析，回答“发生了什么”。
- 数据汇总：计算平均值、中位数、众数、总和、最大值、最小值等基础统计量。
- 数据分布：通过直方图、箱线图观察数据的分布形态和离散程度。
- 对比分析：将当前数据与历史数据、目标数据或同类数据进行对比，如同比、环比增长。
- 构成分析：分析各部分在整体中的占比，如饼图、堆叠柱状图，了解结构变化。
```
- 诊断性分析（Diagnostic Analysis）
```java
回答“为什么发生”，旨在挖掘数据背后的原因。
- 下钻分析：从宏观数据层层深入到微观细节，定位问题根源。例如，销售额下降，下钻到地区、产品、渠道，找到具体是哪个环节出了问题。
- 关联分析：寻找变量之间的相关性。例如，使用皮尔逊相关系数、斯皮尔曼等级相关系数，或者Apriori算法发现频繁项集。
- 归因分析：确定影响结果的关键因素。例如，使用杜邦分析法将净资产收益率拆解为销售利润率、资产周转率和权益乘数，找出驱动因子。
```
- 预测性分析（Predictive Analysis）
```java
回答“将来会发生什么”，基于历史数据推测未来趋势。
- 时间序列分析：使用移动平均、指数平滑、ARIMA模型等方法，预测未来某个时间点的数值，如销量预测、股价走势。
- 回归分析：建立自变量与因变量之间的数学关系，预测连续值。包括线性回归、逻辑回归等。
- 分类算法：预测离散结果，如用户是否会流失、邮件是否为垃圾邮件。常用方法有决策树、随机森林、支持向量机、朴素贝叶斯等。
- 聚类分析：将数据划分为不同的组，发现潜在模式。常用K-Means、DBSCAN等算法，用于用户分群、市场细分。
```
-  规范性分析（Prescriptive Analysis）
```java
回答“我们应该怎么做”，在预测基础上给出最优决策建议。
- 优化算法：在约束条件下寻找最优解，如线性规划、整数规划，用于资源分配、路径优化。
- 模拟仿真：通过蒙特卡洛模拟等方法，评估不同决策方案的风险和收益。
- A/B测试：通过对比实验，验证新策略（如新页面、新算法）的效果，为决策提供数据支持。
```
